# Simon Says Game

A classic memory game built with HTML, CSS, and JavaScript. The game generates a sequence of colors that the player must memorize and repeat in the correct order. With each level, the sequence becomes longer, increasing the challenge and testing the player's memory and concentration.

### Features

* Interactive color-based gameplay
* Increasing difficulty with each level
* Score and level tracking
* Responsive and user-friendly interface
* Instant feedback for correct and incorrect moves

### Technologies Used

* HTML
* CSS
* JavaScript

### How to Play

1. Start the game.
2. Watch the displayed color sequence.
3. Repeat the sequence by clicking the colors in the same order.
4. Progress through levels by successfully matching the sequence.
5. The game ends when an incorrect selection is made.

This project is a great way to learn JavaScript concepts such as DOM manipulation, event handling, arrays, and game logic while creating an engaging and interactive user experience.
